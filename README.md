# India Telecom Analytics — Portfolio Dataset

This package is a synthetic India-oriented telecom dataset and interactive HTML dashboard.

## Important
- All data is simulated for portfolio / learning purposes.
- Plan categories are generic and are NOT commercial plan names from Jio, Airtel, Vi, BSNL, or any other operator.
- Prices are representative portfolio bands in INR and should not be treated as current market offers.

## Generic Plan Categories
- Prepaid Entry
- Prepaid Unlimited
- Prepaid 5G
- Postpaid Individual
- Postpaid Family
- Premium 5G Postpaid
- Business Mobile
- Enterprise Mobility

## India-oriented dimensions
- Telecom Circle
- Zone
- City
- Customer Segment
- Plan Category
- Plan Type
- 4G / 5G Network Technology

## GitHub Pages
Upload all files to the SAME repository root.
Keep the filename exactly `index.html`.
Enable:
Settings > Pages > Deploy from a branch > main > /(root)

The dashboard will then read the CSV files directly from the repository.
